ColorSwatch is a lightweight, web-based color extraction tool that allows users to upload images and instantly view a palette of dominant colors using JavaScript and the Vibrant.js library.

## Features

- Upload an image and preview it in real-time
-  Extract dominant colors with Vibrant.js
-  Client-side processing — no server needed. All in local storage
-  Clean and minimalist UI

##  Tech Stack

- **JavaScript**
- **Vibrant.js**
- **HTML5 / CSS3**
- **FileReader API**
